01 /适用范围与公司主体

本政策说明灵刻起元（重庆）科技有限责任公司（品牌：LINK SOURCE STUDIO，以下简称“我们”）在提供《风暴机甲》（STORMFRAME）的 PICO 版本、相关客服及本政策网页时如何处理信息。

本政策适用于开发测试及正式发行期间提供的上述服务。各版本的功能可能不同，下文所述平台数据处理在相应功能可用且被使用时发生。STORMFRAME 是单人 VR 游戏，平台排行榜不代表多人联机对战。

PICO 独立提供的账号、商店支付和设备系统服务也受其隐私规则约束；我们从平台取得或向平台提交的信息，仍按本政策处理。本政策是信息处理说明，不代替依法需要取得的同意。

02 /游戏内的信息与用途

VR 输入与设备适配

游戏在设备上实时处理头显与控制器的位置、朝向、追踪状态、按键和摇杆输入，以及设备型号和 XR 运行环境信息，用于显示视角、操控机甲及操作菜单。我们不将连续动作轨迹上传至工作室服务器，也不将其用于身份识别、广告或健康判断。

进度、设置和校准

设备本地保存剧情进度、关卡结果、资源、装备与强化状态、存档时间、个人纪录、成就进度，以及语言、音量、字幕和界面偏好，用于继续游戏和保留设置。主动进行手臂校准时，游戏使用头部与双手的相对位置，保存触及距离数值及校准有效状态，以适配动作幅度。

实时输入随游戏运行处理；存档和设置可跨游戏会话保留。成就、排行榜及纳入云备份的记录还会按下一节传输至 PICO，不能视为仅保存在本地。

诊断与反馈

设备本地诊断文件可能包含游戏和系统版本、设备型号、时间、关卡及错误状态。我们不通过游戏自动接收这些诊断文件；您主动向客服发送日志、截图或视频时，我们会处理您提供的内容。PICO 自身的设备诊断按其独立规则运行。

03 /账号、成就、排行榜与云备份

账号与应用授权

游戏通过 PICO 平台处理用户 ID、昵称和应用授权结果，用于识别当前账号、显示玩家名称、区分不同账号的存档及确认应用使用权限。用户 ID 可与本地游戏记录关联，不属于匿名数据。我们不要求另建工作室账号，不收取您的 PICO 密码、验证码或支付卡信息。

成就

游戏与 PICO 平台交换与账号关联的成就标识、进度、解锁状态和解锁时间，用于记录、同步及展示成就。成就可能显示在 PICO 提供的相应界面中，可见范围受平台功能和设置影响。用于判断成就的全部战斗过程并不会因此全部上传。

排行榜与好友榜

游戏向 PICO 提交与账号关联的成绩，包括积分或完成波数、用时和成绩规则版本，并读取排行榜中的用户 ID、昵称、积分及排名，用于更新排名、标记自己的记录和比较游戏成绩。相应榜单可见范围内的其他玩家可以看到榜单展示的昵称和成绩信息。

使用好友榜时，游戏会通过 PICO 请求好友关系权限，并使用平台返回的好友范围排名数据。拒绝该可选权限会影响好友榜，不影响其他不依赖此权限的功能。游戏不将完整好友名单导出至工作室服务器，不将好友关系用于建立游戏外的联系人档案或发送营销消息。好友榜筛选不会自动将其他榜单中的成绩变为私密；可见范围取决于榜单及平台设置。

PICO 云备份

当应用与头显启用 PICO 云存档服务时，由 PICO 备份和恢复应用配置目录中的游戏数据，游戏也可向平台请求备份。内容包括剧情进度、装备与强化、成就、个人纪录和必要设置，以及相应的存档时间与账号关联信息。目录中随游戏写入的诊断记录也可能包含在文件备份中；这不代表工作室会自动收到这些诊断文件。

备份与 PICO 账号关联，由 PICO 提供存储与恢复服务，用于重装应用、更换或恢复设备后继续游戏。这是文件备份与恢复，不承诺跨平台存档互通或多设备即时合并。您可在 PICO 设备提供的设置中管理云存档。清除本地数据或关闭后续备份不等于删除已有云端副本；恢复备份后本地数据可能重新出现。管理与删除方式见第 7 节。

05 /服务提供方与数据接收方

  • PICO

    通过设备运行时及 PICO 平台 SDK 提供 VR 运行支持、账号、授权、成就、排行榜与云备份。相关数据按第 3 节在设备与 PICO 服务之间传输。平台自行进行的支付、安全和设备处理不代表全部信息都会交给工作室。中国大陆平台服务由海南创见未来科技有限公司及其关联公司提供，详见 PICO 中国大陆隐私政策；其他地区的服务主体与独立处理安排见 PICO 地区隐私政策。

  • 其他玩家

    可在相应榜单及平台可见范围内查看您的昵称和成绩信息。我们不会因提供排行榜而公开您的客服邮件或云备份文件。

  • Unreal Engine / OpenXR

    用于渲染、VR 输入及设备兼容。游戏通过设备运行时处理这些输入；引擎或组件的使用不意味着工作室接收全部设备数据。

  • 腾讯 QQ 邮箱

    承载客服邮件及附件。通信服务规则见 腾讯隐私保护指引及 QQ 邮箱专项说明；我们收到和使用的邮件仍受本政策约束。

  • GitHub Pages

    托管本政策网页。GitHub 会为安全目的记录访问者 IP 地址，参见 Pages 数据收集说明及 GitHub 隐私声明。访问本页不会上传游戏存档。本页没有登录、提交表单、广告或访客统计脚本，也不主动写入 Cookie。

我们不出售个人信息，不将上述数据用于广告定向。向服务商提供的信息限于所述服务需要的范围；依法披露或因组织变更转移资料时，我们会履行适用的告知义务并采取相应保护措施。

06 /保存地点、期限与跨境处理

  • 实时输入：在设备上随游戏运行处理，不作为工作室服务器上的动作档案保存。
  • 本地游戏数据：存档、设置、账号关联信息及诊断记录位于设备游戏数据目录或您导出的位置，保留至被覆盖、重置或删除。
  • 成就、排行榜及云备份：由 PICO 的相关服务保存，以供同步、展示和恢复。工作室处理的关联信息仅在提供所述功能所需期间保留，或在有效删除请求后按第 7 节处理。PICO 独立持有的信息受其保存和删除规则约束。
  • 客服资料：公司在中国大陆处理。保留期间限于解决请求以及必要的后续沟通、争议处理或法定义务，之后删除或匿名化。依法需保留的部分限制用途。
  • 网页访问：GitHub 及其服务商可能在美国和其他国家处理访问数据。

PICO 的中国大陆隐私政策说明，其在中国境内运营过程中收集和产生的个人信息存储于中国境内。其他地区的 PICO 服务可能涉及跨境处理，地点及安排请查看适用地区的 PICO 隐私政策。上述平台存储安排不代表本政策网页的托管地点。境外用户发送给我们的客服资料由中国大陆的公司接收和处理。涉及适用法律要求的跨境保障、告知或同意时，我们会在开展相应处理前落实；本政策本身不代替这些程序。

07 /管理、删除与其他权利

删除设备数据与系统云备份

可以使用设备提供的应用数据管理功能清理本地数据，或按照设备说明卸载应用并清理残留文件。这可能删除进度和设置，自行导出的副本须另行删除。未持有本地副本时，我们无法远程代删，但可以协助。

已有 PICO 云备份由平台管理。请先检查头显提供的云存档设置；如需删除 STORMFRAME 的已有云端副本，请通过 PICO 的客服或隐私请求渠道提出，并可联系我们协助。中国大陆用户可在设备“设置—通用—反馈”中联系 PICO，或使用 PICO 隐私政策中的联系方式；其他地区请使用 当地 PICO 隐私渠道。删除本地数据、停止后续备份与删除旧备份须分别处理。

请求删除账号关联记录、成就、排行榜或客服资料

发送邮件至 3868577144@qq.com，主题可写“STORMFRAME PICO 数据删除”或“STORMFRAME PICO Data Deletion”。请说明希望删除的资料及对应功能；如需定位记录，可提供应用内用户 ID、榜单昵称或相关记录说明。请勿发送密码或验证码。此渠道适用于所有地区的用户。

我们会核验请求并删除我们控制且可删除的数据，包括适用的账号关联记录、成就或排行榜记录及客服资料；涉及 PICO 接口权限或需由平台完成的操作，我们会说明可处理范围并协助提供平台处理途径。删除榜单记录、平台成就或本地存档可能需要分别操作，单独删除工作室资料不会自动注销 PICO 账号。PICO 独立持有的账号或其他记录可通过其隐私及账号管理渠道处理。

其他权利与答复

您可依法请求查阅、复制、更正、删除信息，限制或反对处理，撤回同意及行使适用的数据可携权。我们只核验处理请求所需的信息，在适用法律期限内答复，并说明处理结果或无法处理的原因。依法必须保留的信息限制用途。我们不因您行使权利而给予不当差别待遇。

可在设备及平台设置中管理相应可选权限和备份功能。撤回同意不影响此前依法进行的处理；必要输入或账号服务不可用时，相关功能可能无法运行。

在适用欧洲经济区或英国规则时，提供您请求的游戏及支持基于履行合同；必要且适度的安全防护和故障排查基于经权衡的合法利益；法定保存基于法定义务；依法需同意的可选处理基于同意。您可向有管辖权的数据保护机构投诉。

09 /安全、更新与联系

我们根据用途和风险限制信息访问，采取合理的保护措施。不存在可以保证绝对安全的存储或传输方式。发生相关安全事件时，我们会采取补救措施并依法通知或报告。

如功能、处理数据、用途或接收方发生变化，我们会更新本政策，并在需要时通过游戏或官网作显著提示、取得相应同意。我们保留已生效政策的历史版本。中英文版本描述相同的处理安排，语言差异不缩减您的法定权利。

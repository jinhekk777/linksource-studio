01 /适用范围与公司主体

本政策说明灵刻起元（重庆）科技有限责任公司（品牌：LINK SOURCE STUDIO，以下简称“我们”）在提供《风暴机甲》（STORMFRAME）的 Meta Quest 版本、相关客服及本政策网页时如何处理信息。

本政策适用于开发测试及正式发行期间提供的上述服务。各版本的功能可能不同，下文所述平台数据处理在相应功能可用且被使用时发生。STORMFRAME 是单人 VR 游戏，平台排行榜不代表多人联机对战。

Meta 独立提供的账号、商店支付和设备系统服务也受其隐私规则约束；我们从平台取得或向平台提交的信息，仍按本政策处理。本政策是信息处理说明，不代替依法需要取得的同意。

02 /游戏内的信息与用途

VR 输入与设备适配

游戏在设备上实时处理头显与控制器的位置、朝向、追踪状态、按键和摇杆输入，以及设备型号和 XR 运行环境信息，用于显示视角、操控机甲及操作菜单。我们不将连续动作轨迹上传至工作室服务器，也不将其用于身份识别、广告或健康判断。

进度、设置和校准

设备本地保存剧情进度、关卡结果、资源、装备与强化状态、存档时间、个人纪录、成就进度，以及语言、音量、字幕和界面偏好，用于继续游戏和保留设置。主动进行手臂校准时，游戏使用头部与双手的相对位置，保存触及距离数值及校准有效状态，以适配动作幅度。

实时输入随游戏运行处理；存档和设置可跨游戏会话保留。成就、排行榜及纳入系统云备份的记录还会按下一节传输至 Meta，不能视为仅保存在本地。

诊断与反馈

设备本地诊断文件可能包含游戏和系统版本、设备型号、时间、关卡及错误状态。我们不通过游戏自动接收这些诊断文件；您主动向客服发送日志、截图或视频时，我们会处理您提供的内容。Meta 自身的设备诊断按其独立规则运行。

03 /账号、成就、排行榜与云备份

账号与应用授权

游戏通过 Meta 平台处理应用内用户 ID 和应用授权结果，用于识别当前账号、区分不同账号的存档及确认应用使用权限。用户 ID 可与本地游戏记录关联，不属于匿名数据。我们不要求另建工作室账号，不收取您的 Meta 密码、验证码或支付卡信息。

成就

游戏与 Meta 平台交换与账号关联的成就标识、进度、解锁状态和解锁时间，用于记录、同步及展示成就。成就可能显示在 Meta 提供的相应界面中，可见范围受平台功能和设置影响。用于判断成就的全部战斗过程并不会因此全部上传。

排行榜与好友榜

游戏向 Meta 提交与账号关联的成绩，并读取排行榜记录。涉及的数据为昵称、积分、排名、波数和用时，用于生成、更新及展示排名，以及比较游戏成绩。相应榜单可见范围内的其他玩家可以看到榜单展示的昵称和成绩信息。

好友榜使用 Meta 返回的好友范围排名数据，以展示对应关系范围内的成绩。这类数据仅用于好友榜功能，不用于建立游戏外的联系人档案或发送营销消息。好友榜筛选不会自动将其他榜单中的成绩变为私密；具体可见范围取决于您使用的榜单及平台设置。

Meta 系统云备份

当应用和设备启用 Meta Cloud Backup 时，由 Meta 系统备份并恢复游戏文件。备份内容包括剧情进度、装备、成就、个人纪录和必要设置，用于重装应用、更换设备或恢复设备后继续游戏。备份与 Meta 账号关联，由 Meta 提供存储与恢复服务；这不意味着与其他游戏平台的存档互通。

您可以在设备设置中管理云备份，并在 Meta 提供的云备份管理页面删除已有备份。清除本地存档不等于删除云端副本，恢复备份后本地数据可能重新出现。具体删除方式见本政策第 7 节。

04 /联系客服时提供的信息

05 /服务提供方与数据接收方

  • Meta

    提供 Quest 运行时、账号、授权、成就、排行榜与系统云备份。相关游戏记录在设备与 Meta 服务之间传输，用于上述功能。平台自行进行的支付、安全和设备处理不代表全部信息都会交给工作室。服务主体及其独立处理安排见 Meta Platforms Technologies 补充隐私政策。

  • 其他玩家

    可在相应榜单及平台可见范围内查看您的昵称和成绩信息。我们不会因提供排行榜而公开您的客服邮件或云备份文件。

  • Unreal Engine / OpenXR

    用于渲染、VR 输入及设备兼容。游戏通过设备运行时处理这些输入；引擎或组件的使用不意味着工作室接收全部设备数据。

  • 腾讯 QQ 邮箱

    承载客服邮件及附件。通信服务规则见 腾讯隐私保护指引及 QQ 邮箱专项说明；我们收到和使用的邮件仍受本政策约束。

  • GitHub Pages

    托管本政策网页。GitHub 会为安全目的记录访问者 IP 地址，参见 Pages 数据收集说明及 GitHub 隐私声明。访问本页不会上传游戏存档。本页没有登录、提交表单、广告或访客统计脚本，也不主动写入 Cookie。

我们不出售个人信息，不将上述数据用于广告定向。向服务商提供的信息限于所述服务需要的范围；依法披露或因组织变更转移资料时，我们会履行适用的告知义务并采取相应保护措施。

06 /保存地点、期限与跨境处理

  • 实时输入：在设备上随游戏运行处理，不作为工作室服务器上的动作档案保存。
  • 本地游戏数据：存档、设置、账号关联信息及诊断记录位于设备游戏数据目录或您导出的位置，保留至被覆盖、重置或删除。
  • 成就、排行榜及云备份：由 Meta 的相关服务保存，以供同步、展示和恢复。工作室处理的关联信息仅在提供所述功能所需期间保留，或在有效删除请求后按第 7 节处理。Meta 独立持有的信息受其保存和删除规则约束。
  • 客服资料：公司在中国大陆处理。保留期间限于解决请求以及必要的后续沟通、争议处理或法定义务，之后删除或匿名化。依法需保留的部分限制用途。
  • 网页访问：GitHub 及其服务商可能在美国和其他国家处理访问数据。

Meta 平台信息可能在您所在国家或地区以外处理，具体地点和传输安排见其隐私说明。境外用户发送给我们的客服资料由中国大陆的公司接收和处理。涉及适用法律要求的跨境保障、告知或同意时，我们会在开展相应处理前落实；本政策本身不代替这些程序。

07 /管理、删除与其他权利

删除设备数据与系统云备份

可以使用设备提供的应用数据管理功能清理本地数据，或按照设备说明卸载应用并清理残留文件。这可能删除进度和设置，自行导出的副本须另行删除。未持有本地副本时，我们无法远程代删，但可以协助。

在 Meta 的 Cloud Backups 管理页中找到 STORMFRAME，可查看并删除已有备份；入口和步骤见 Meta 官方云备份说明。请分别检查后续备份开关与已有副本：删除本地数据不会自动删除备份，关闭后续备份也不代表已清除旧副本。

请求删除账号关联记录、成就、排行榜或客服资料

发送邮件至 3868577144@qq.com，主题可写“STORMFRAME Quest 数据删除”或“STORMFRAME Quest Data Deletion”。请说明希望删除的资料及对应功能；如需定位记录，可提供应用内用户 ID、榜单昵称或相关记录说明。请勿发送密码或验证码。此渠道适用于所有地区的用户。

我们会核验请求并删除我们控制且可删除的数据，包括适用的账号关联记录、成就或排行榜记录及客服资料；涉及 Meta 接口权限或需由平台完成的操作，我们会说明可处理范围并协助提供平台处理途径。删除榜单记录、平台成就或本地存档可能需要分别操作，单独删除工作室资料不会自动注销 Meta 账号。Meta 独立持有的账号或其他记录可通过其隐私及账号管理渠道处理。

其他权利与答复

您可依法请求查阅、复制、更正、删除信息，限制或反对处理，撤回同意及行使适用的数据可携权。我们只核验处理请求所需的信息，在适用法律期限内答复，并说明处理结果或无法处理的原因。依法必须保留的信息限制用途。我们不因您行使权利而给予不当差别待遇。

可在设备及平台设置中管理相应可选权限和备份功能。撤回同意不影响此前依法进行的处理；必要输入或账号服务不可用时，相关功能可能无法运行。

在适用欧洲经济区或英国规则时，提供您请求的游戏及支持基于履行合同；必要且适度的安全防护和故障排查基于经权衡的合法利益；法定保存基于法定义务；依法需同意的可选处理基于同意。您可向有管辖权的数据保护机构投诉。

请遵守游戏商店标示的年龄分级、Meta 设备与账号适用年龄及当地监护规则。游戏不因在商店可见就适用于所有年龄。本政策不替代平台的未成年人保护规则。

需要监护人同意或其他儿童隐私措施时，我们会按适用法律落实。监护人认为儿童向我们提供了不应处理的信息，可通过上述邮箱联系我们核实或删除。

09 /安全、更新与联系

我们根据用途和风险限制信息访问，采取合理的保护措施。不存在可以保证绝对安全的存储或传输方式。发生相关安全事件时，我们会采取补救措施并依法通知或报告。

如功能、处理数据、用途或接收方发生变化，我们会更新本政策，并在需要时通过游戏或官网作显著提示、取得相应同意。我们保留已生效政策的历史版本。中英文版本描述相同的处理安排，语言差异不缩减您的法定权利。
